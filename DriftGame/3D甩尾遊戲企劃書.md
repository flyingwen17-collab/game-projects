## 2. 核心玩法設計

### 2.1 甩尾機制（最重要的部分）
- **進入甩尾**：高速中「轉向 + 手煞車（Space）」或急收油門重心轉移。
- **維持甩尾**：反打方向盤（counter-steer）+ 油門控制滑移角度。系統提供**輔助反打**（自動補一部分反方向力），降低門檻。
- **退出甩尾**：回正方向、鬆手煞車，車身自動穩定。
- **滑移角（Slip Angle）**：車頭朝向與實際速度方向的夾角。角度 15°~70° 之間且車速 > 30km/h 判定為「甩尾中」。

### 2.2 計分系統
- **基礎分**：甩尾期間每秒依「滑移角 × 車速」累積。
- **連段（Combo）**：甩尾結束後 2 秒內再次進入甩尾 → 倍率 +0.5x（上限 5x）。
- **失誤**：撞牆/出界 → 當前未結算分數歸零、倍率重置。
- **加分事件**：貼牆近距離甩尾（Proximity Bonus）、連續彎道一鏡到底、過彎頂點（Apex）通過。
- **結算**：總分 → 星級評價（1~3 星），解鎖條件掛在星數上。

### 2.3 遊戲模式（依開發順序）
1. **自由練習**：無限時跑圖，練手感（第一個做）。
2. **計分挑戰**：限時內衝高分，星級解鎖。
3. **計時賽**：純比圈速，甩尾是過彎工具。
4. （延伸）幽靈車對戰：與自己最佳紀錄的 Ghost 比賽。

### 2.4 操作配置

| 油門 / 煞車 | W / S | RT / LT |
| 轉向 | A / D | 左搖桿 |

## 3. 技術架構

### 3.1 專案設定
- **Unity 版本**：Unity 6（6000.x）或 2022.3 LTS
- **渲染管線**：URP（效能好、跨平台、夠漂亮）
- **必裝套件**：Input System、Cinemachine、TextMeshPro、（選配）ProBuilder 做賽道白模
- **物理**：內建 PhysX，`Fixed Timestep = 0.02`，車輛邏輯全部寫在 `FixedUpdate`

### 3.2 車輛物理方案（關鍵決策）

**採用方案 A：WheelCollider（Unity 內建）**
- Rigidbody（質量約 1200kg，重心用 `centerOfMass` 壓低）+ 4 個 WheelCollider。
- 甩尾核心 = 動態調整**後輪側向摩擦曲線**（`sidewaysFriction.stiffness`）：
  - 手煞車按下 → 後輪 stiffness 從 1.0 降到 ~0.5，後輪抓地瞬間變低 → 甩出去。
  - 甩尾中依滑移角插值恢復 stiffness，做出「可控的滑」。
- 額外輔助力：
  - **下壓力**：速度平方 × 係數，高速更穩。
  - **轉向助力**：甩尾中對車身施加輔助 torque，讓玩家更容易維持角度。
  - **速度感應轉向**：高速時降低最大轉向角，避免高速一拉就轉圈。

**備案方案 B：自製 Raycast 懸吊物理**（每輪一條射線 + 自算懸吊彈簧與摩擦）。手感天花板更高、更街機，但開發成本約多一倍。**先用 A 做出可玩版本，若手感調不出來再評估換 B**——兩者對外介面（輸入 → 車輛）設計成一致，可替換。

### 3.3 攝影機
- **Cinemachine** Third Person Follow：
  - 追蹤車輛「速度方向」而非車頭朝向 → 甩尾時能看到車身橫滑的帥氣角度。
  - 速度越快 FOV 越大（60→75）、攝影機距離微拉遠。
  - 甩尾時輕微螢幕震動與側傾。
- 三組視角：追尾（預設）/ 引擎蓋 / 遠景，C 鍵循環。

### 3.4 腳本架構（資料夾與職責）

```
Assets/
├── _Project/
│   ├── Scripts/
│   │   ├── Vehicle/
│   │   │   ├── CarController.cs      // 讀輸入、油門煞車轉向、手煞車
│   │   │   ├── CarPhysics.cs         // WheelCollider 管理、摩擦動態調整
│   │   │   ├── DriftDetector.cs      // 滑移角計算、甩尾狀態判定（發事件）
│   │   │   └── CarVisuals.cs         // 輪胎轉動、車身側傾、輪胎痕、煙霧
│   │   ├── Gameplay/
│   │   │   ├── DriftScoring.cs       // 訂閱甩尾事件 → 計分、連段
│   │   │   ├── GameModeManager.cs    // 練習/挑戰/計時模式切換
│   │   │   ├── LapTimer.cs           // 檢查點與圈速
│   │   │   └── CheckpointSystem.cs
│   │   ├── UI/
│   │   │   ├── HUDController.cs      // 時速表、分數、連段倍率
│   │   │   └── MenuController.cs     // 主選單、暫停、結算
│   │   ├── Camera/
│   │   │   └── CameraSwitcher.cs
│   │   └── Core/
│   │       ├── GameManager.cs        // 場景流程、存檔
│   │       └── AudioManager.cs
│   ├── Prefabs/  ├── Materials/  ├── Scenes/  ├── Settings/（Input Actions、URP Asset）
│   └── Art/（模型、貼圖、音效）
```

- 系統間用 **C# event** 解耦：`DriftDetector` 發 `OnDriftStart / OnDriftUpdate(angle, speed) / OnDriftEnd`，計分、音效、特效、UI 各自訂閱，互不相依。
- 車輛參數集中在 **ScriptableObject（CarConfig）**：馬力、質量、摩擦曲線、甩尾參數——調手感不用改程式碼，也方便之後做多車種。

### 3.5 視覺回饋（甩尾爽感三件套）
1. **輪胎痕**：TrailRenderer 於後輪接地點，甩尾中才生成。
2. **輪胎煙**：Particle System，濃度隨滑移角。
3. **速度感**：FOV 拉伸 + 螢幕邊緣微量 Motion Blur（URP Volume）。

### 3.6 音效
- 引擎聲：依 RPM 調整 pitch（1 個 loop 素材即可起步）。
- 輪胎摩擦聲：甩尾中播放，音量隨滑移角。
- 撞擊、UI、結算音效 + 一首 BGM。
- 素材來源：freesound.org / Unity Asset Store 免費包。

### 3.7 美術資源策略
- **先用免費資源**：Unity Asset Store「ARCADE: Free Racing Car」等免費車模；賽道用 ProBuilder 拉白模 + 免費材質。
- 原則：**手感 > 畫面**。前期全部灰盒（greybox），手感確定後才換美術。

## 5. UI 流程

```
主選單 ─→ 選模式 ─→ 選賽道 ─→ 遊戲中(HUD) ─→ 結算畫面 ─→ 重試 / 回選單
                                    │
                                  暫停選單
```

- **HUD**：時速（大字）、當前甩尾分數（甩尾時彈出、跟隨累積）、連段倍率、計時、小地圖（後期）。
- **結算**：總分動畫滾動、星級、最長連段、最速圈、「新紀錄！」標示。
- 存檔：JSON 存 `persistentDataPath`（各賽道最高分、星數、解鎖狀態）。

## 7. 風險與對策

| 風險 | 對策 |
|------|------|
| WheelCollider 手感調不出來 | 參數全在 CarConfig 可快速迭代；真不行換 Raycast 方案 B（介面已預留） |
| 甩尾太難或太簡單 | 輔助反打強度做成 0~1 滑桿，難度分級 |
| 範圍膨脹做不完 | 嚴格照里程碑，每階段有明確驗收；美術永遠最後 |
| 車輛翻覆、物理爆炸 | 壓低重心、防翻 torque、R 鍵重置保底 |
